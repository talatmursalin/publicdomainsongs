Despite this repository's name, these songs are not public domain: they are licensed under
Creative Commons Attribution. Credit the artist when you use them.

## Layout

Each record has its own folder, named by its id in GRAMO's catalog, with one AAC file (`.m4a`,
96 kbps, 44.1 kHz stereo) per song and the cover. Each version of a record is tagged
`<record id>-v<n>`, and GRAMO downloads from a tag, so a published version never changes: a new
version of a record gets new files and a new tag, and older app versions keep working.
